## 二、三大实战项目复盘

### 项目一 · 智能知识库问答系统（Day 57-70）
- 技术栈：Next.js + LangChain.js + Pinecone + OpenAI
- 串联能力：文档切分（Day 18/58）→ 向量化（Day 37/59）→ 语义检索（Day 39/60）→ 流式对话（Day 27/61）→ 多轮上下文（Day 24/64）→ 测试优化（Day 65）→ 部署（Day 66）
- 产物：带引用溯源（Day 63）的 RAG 问答站

### 项目二 · 多 Agent 协作编程助手（Day 71-78）
- 技术栈：Node.js + Vercel AI SDK + MCP
- 串联能力：PM/Coder/Reviewer/Tester 四角色（Day 72-75）→ Supervisor 编排（Day 44/76）→ MCP 工具集成（Day 77）→ 端到端测试优化（Day 78）
- 产物：能「需求→编码→审查→测试」自闭环的编程 Agent

### 项目三 · MCP 工具服务器（Day 79-83）
- 技术栈：TypeScript + @modelcontextprotocol/sdk + Prisma
- 串联能力：MCP 概念（Day 50/51）→ 工具设计（Day 30/31）→ 数据库/API/文件工具（Day 48/49/73）→ 协议合规与测试（Day 65/83）
- 产物：标准 MCP server（7 个工具），**被项目二真实调用**，形成自洽闭环

> 三个项目构成完整叙事：**消费知识（RAG）→ 编排智能（多 Agent）→ 暴露能力（MCP）**，正好是「Agent 工程」的三根支柱。
